## Critical

### C1 · Production Android signing passwords still in git history — HUMAN REQUIRED
**Status:** Open (cannot fully automate)  
**Evidence:** `git log -p -S 'jwnews2024secure'` / `-S 'JWHabits2026!'`  
**Impact:** Anyone with repo read can sign malicious Play updates for `com.ashbi.jwnews`.  
**Mitigation in this PR:** HEAD already env-based; removed hardcoded absolute keystore path; refreshed `docs/keystore-rotation-2026-07.md` status banner.  
**You must:** follow that runbook — Play upload-key reset, then history purge.

### C2 · `replaceState` threw on every tab focus / cross-tab sync — FIXED
`useState` only returns `[state, setState]`; code destructured a third `setStateFull` → `undefined` → `TypeError` on `visibilitychange` / `storage`. Midnight rollover while the tab stayed open never refreshed UI.  
**Patch:** `src/hooks/useHabitState.js` — `replaceState` uses `setStateInternal`.

### C3 · PWA “Update” was a no-op — FIXED
`forceUpdate()` posted `{ type: 'SKIP_WAITING' }` but `src/sw.js` had no message listener.  
**Patch:** SW handles `SKIP_WAITING` → `skipWaiting()`; `pwa.js` reloads on `controllerchange`.

## High (all patched)

| ID | Issue | Patch |
|---|---|---|
| H1 | No CSP / HSTS | `nginx.conf` CSP + HSTS |
| H2 | nginx `add_header` inheritance dropped security headers on `/sw.js` + assets | Repeat headers in those locations |
| H3 | SW cached any image host + dead `api.*` / jw.org / Google Fonts routes | Same-origin-only image/font caches; drop unused routes; validate notification URLs |
| H4 | PR builds pushed GHCR `:latest` | `build-and-push.yml` — no push on PR; `:latest` only on non-PR |
| H5 | Share target opened any `https://` URL (phishing) | Allowlist `*.jw.org` / app host via `sanitizeShareUrl` |
| H6 | Install/Update storage threw in private browsing | try/catch around getItem/setItem |
| H7 | Unhandled PWA / notification promises | `.catch` / try-await on install, SW ready, reminder timers |
| H8 | Weekly Watchtower schedulers never armed | Wired in `SettingsAccordion` with cleanup |
| H9 | Note typing thrash (persist every keystroke) | Real 300ms debounce + unmount cleanup |
| H10 | Triple `usePWA()` mounts / leaked SW listeners | Single `usePWA` in `HomeWithChrome`; proper listener cleanup |
| H11 | Share chunk always loaded on Home | `React.lazy` Share route |

Also included with High hardening: `allowBackup="false"`, narrowed FileProvider paths, hardened `.dockerignore`, strip query/hash from error-log URLs.
